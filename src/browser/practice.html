How it works

Each round, both sides submit one free move or attack. Moves use unit-specific ranges. Terrain can block movement, and units can counterattack. Your orders are validated by the original HexaWars rules engine, which runs locally in a Web Worker.

Practice uses the original 81-cell rules board until the new balanced map is formally adopted. There is no account, ranking, cloud matchmaking, or reliable anti-cheat protection in a local game.
